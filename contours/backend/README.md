# Приём ответов (опция «агрегация на входе»)

Референс-бэкенд для варианта **«сервер принимает ответы и хранит их append-only
со строгим доступом»**. Это Cloudflare Worker + KV: дёшево (бесплатного тира
хватает), без своей инфраструктуры, разворачивается за пару минут.

## Что он гарантирует (и что нет)

- ✅ **Не логирует IP** и заголовки запроса.
- ✅ **Санирует на входе**: убирает поминутную латентность и время на вопрос,
  огрубляет метки времени до суток, режет сверхдлинные строки.
- ✅ **Append-only** в KV под случайным ключом.
- ✅ **Отдаёт данные только по токену фасилитатора** и **только при N ≥ MIN_N**.
- ✅ **CORS** ограничен вашим origin.
- ❌ **Не** zero-knowledge: держатель `FAC_TOKEN` видит санированные
  индивидуальные записи (включая открытые ответы). **Выдавайте токен человеку
  вне линии подчинения команды** (внешний фасилитатор / HR-партнёр).

Открытые ответы всё равно содержательно атрибутируемы — предупреждение об этом
показывается респонденту на старте. Сервер не превращает их в анонимные.

## Развёртывание

```sh
cd contours/backend
npm i -g wrangler            # или npx wrangler ...
wrangler kv namespace create RESPONSES   # вставьте id в wrangler.toml
wrangler secret put FAC_TOKEN            # придумайте длинный случайный токен
wrangler deploy
```

После деплоя вы получите URL вида `https://contours-intake.<subdomain>.workers.dev`.

## Подключение опроса

В `contours/config.js` задайте:

```js
submitEndpoint: "https://contours-intake.<subdomain>.workers.dev/submit",
```

Теперь по завершении ответ уходит POST-запросом автоматически (респондент всё
равно может дополнительно скачать файл). Ключей/секретов в `config.js` нет —
там только публичный URL.

## Как фасилитатор забирает данные

Токен **не вводите в браузере** — тяните ответы из терминала и вставляйте в
`report.html`:

```sh
curl -s -H "Authorization: Bearer $FAC_TOKEN" \
  "https://contours-intake.<subdomain>.workers.dev/report?key=team-strategy-2026q1" \
  > responses.json
```

- При `N < MIN_N` вернётся `{ "gated": true, "n": ... }` — агрегат ещё рано.
- Иначе — `{ "responses": [ ... ] }`. Возьмите массив `responses` и вставьте его
  в поле ввода отчёта (или сохраните как файл и загрузите кнопкой). Дальше отчёт
  считается в браузере как обычно.

## Хранение и удаление

KV не чистится сам. После разбора волны удалите ключи группы:

```sh
# список ключей
wrangler kv key list --binding RESPONSES | jq -r '.[].name' | grep '^team-strategy-2026q1:'
# удалить конкретный ключ
wrangler kv key delete --binding RESPONSES "team-strategy-2026q1:<uuid>"
```

Договоритесь о сроке хранения заранее и удаляйте сырьё после того, как отчёт
собран и согласован.
